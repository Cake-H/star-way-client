# 星途背景图片资源

本目录用于放置「星途」系统的可选背景图片。若未放置图片，系统会自动使用 CSS 生成的星空背景（渐变 + 闪烁星点 + 流星），效果依然完整。

## 当前用途

| 文件名 | 用途 | 说明 |
|---|---|---|
| `space-bg.jpg` | 登录页深色背景、主应用浅色背景叠加层 | 检测到后自动启用，未检测到则回退 CSS |

> 也支持 `.webp` 格式。如需使用 WebP，请将文件命名为 `space-bg.webp`。

## 图片规范

- **建议尺寸**：1920×1080 或更高，系统会自动 cover 全屏
- **建议色调**：深空蓝紫色系，例如 `#050814` → `#0b1028` → `#1b2a6a`
- **内容建议**：
  - 星星、星云、柔和光晕
  - 避免过于卡通、高饱和度或复杂的前景元素
  - 避免在画面中心放置高亮物体，以免干扰表单阅读
- **推荐关键词**：`milky way dark`、`nebula dark blue purple`、`starry night sky`、`deep space stars`、`galaxy dark background`
- **推荐来源**：
  - Unsplash（搜索上方关键词）
  - NASA APOD
  - Pexels / Pixabay

## 如何替换

1. 下载符合规范的图片；
2. 重命名为 `space-bg.jpg`（或 `space-bg.webp`）；
3. 放入本目录，覆盖现有文件；
4. 刷新页面即可生效，无需重启开发服务器。

## 无图片时的行为

若本目录没有 `space-bg.*`，`StarryBackground` 组件会完全使用 CSS 渐变与动画生成星空背景，视觉体验依然完整，请放心。
