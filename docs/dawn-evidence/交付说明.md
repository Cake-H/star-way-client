## 二、规范偏差说明（共 5 处，均为最小必要）

1. **index.html +9 行**：规范第二节强制要求「index.html 内联脚本在首帧前读 localStorage 防 FOUC」，
   与白名单冲突，按状态机章节（更高优先级）执行。纯新增 `<script>`，未动任何既有标签。
2. **src/style.css +2 行**：新增 `@import './theme/dawn.css'` + 一行注释。
   dawn.css 必须被加载，全局样式文件追加规则属白名单①允许的「追加」范畴（未改既有规则）。
3. **着色器补声明 `float rot = uPhase * PI`**：参考实现漏声明 `rot`，不补无法编译；
   语义即参考注释所述「自转 180°」。另新增 `uScale` uniform 属规范明示允许的「尺寸参数」
   （对齐原版星球直径 = 画布 1/3，PLANET_VIEW_SCALE = 1/(0.5742×3)）。
4. **揭示层渐变色值加兜底**：`var(--hero-sky-glow, #f5e1c4)` 等。揭示层在 data-theme 翻转前
   （仍是 night）就要扩张，此时 dawn 令牌未挂上 :root，无兜底则整张渐变失效（取证中发现并修复）。
   兜底值与规范令牌逐字一致，未改任何色值。
5. **WebGL 画布混合管线改为预乘**（v2）：规范原文 `premultipliedAlpha:false + SRC_ALPHA` 在数学上
   无法在亮主题下成立——浏览器合成非预乘画布时会把 alpha 再乘一次
   （`out = (col·a)·a² + dst·(1-a²)`），任何 a<1 的光晕落在白昼上都是压暗（用户反馈的"黑云"，
   实测球上方白昼亮度 240→159）。改为 `premultipliedAlpha:true + ONE/ONE_MINUS_SRC_ALPHA` 后，
   着色器光晕分支直接输出合成贡献：夜间输出 `light·a³ / a²`（与原管线合成结果逐位一致，
   夜间基线不受影响），破晓随 uPhase 过渡为纯加法增亮 `light·win / 0`（只增亮、绝不压暗）；
   `win` 为画布边缘归零窗口 × 0.45（加法模式下远晕必须收进画布内，否则露出矩形硬边）。
   球面分支（alpha=1）两种管线下输出完全相同。

## 二补、交付后缺陷与修复（v2）

### 缺陷 A：破晓态星球上方一团"黑云"（用户截图所指）
- **根因**：偏差⑤所述的 alpha 双重相乘。光晕色（暖金，亮度 < 白昼背景）经非预乘管线合成后
  把亮天压暗，最远端 `exp(-g·1.5)` 弱晕在球上方形成大团暗斑（实测 -31~-80 亮度）。
- **修复**：见偏差⑤。破晓态光晕改为纯加法增亮，夜间观感逐位复现。
- **验证**：`fix5-dawn-rest.png` 球心向上亮度剖面单调无凹陷（球盘 158~166 暖金 →
  日冕 254 白热 → 天空 233~250），同点对比夜间 +30~+225；隔离探针确认光晕输出
  `C=(145,112,62), A=0`（纯加法）。t=50% 帧 `fix5-p50.png` 暖金无黑灰。

### 缺陷 B：破晓终点点击无法回夜（以及更深一层的"回夜后无法再次入晓"）
- **根因①（用户直击）**：GSAP 3 的 `play()` 强制正向播放（重置 reversed），
  原代码 `tl.reversed(true); tl.play()` 在破晓终点是空操作。修复：回夜走 `tl.reverse()`。
- **根因②（修复①后实测暴露）**：GSAP 3.15 中 reversed 即负 timeScale。反向播完残留 `ts=-1`，
  原代码先 `tl.timeScale(1)` 归一化速率——这一调用会把残留负速率翻正并**立即起播**，
  使随后的 `isActive()` 误判为"中途"，执行"中途反转"又翻回 `ts=-1`，净效果为零
  （表现为回夜后点击星球再也无法入晓）。
- **修复**（useDawnTransition.ts `toggleDawn`）：`isActive()` 判断前置，速率归一化只在
  静止分支内执行。
- **验证（全部走真实点击入口，非 progress 步进）**：
  - 完整双向循环 ×4（晓↔夜，含反向完结后的再触发）：4/4 归位正确，localStorage 同步；
  - 中途反转：正向 62% 处反点 → 折返回晓 ✓；nav 入口 2× 速率双向 ✓、nav 途中反转 ✓；
  - 快速连点 ×10（130ms 间隔真实点击）：方向逐次翻转无卡死，静置归位
    `{theme:night, ls:night, prog:0, active:false, reveal:none}` ✓；
  - 修复后夜间首屏 vs 基线像素差 8.61%（修复前 8.92%，同口径允许区域：星球盘/导航按钮/噪声底）✓。

## 二补二、v3 返修：白昼恒星态四缺陷（用户驳回 → 根因 → 修复 → 复验）

### 缺陷确认（修复前实测，`v3-before-dawn-rest.png`）

| # | 用户指出 | 实测确认 |
|---|---|---|
| 1 | 满屏黄色洗屏 | 球左 4R 处 hero 内部亮度 (239,228,212)，暖雾铺满 Hero |
| 2 | 星球是暗色剪影 | 球心亮度 167 < 周围天空 233~250，倒挂 |
| 3 | 光晕没有层次 | 1.0~1.6R 光冕全部顶到 250~255 白爆，无分层 |
| 4 | 球体没有质感 | 平涂芥末色盘，无高光/纹理/菲涅尔环 |

### 根因

- **剪影**：旧着色器方位角 `az = mix(-0.9, 2.24, uPhase)`，uPhase=1 时光源转到球体**背面**
  （球心 dl≈-0.6），球面只剩环境光 0.76 → 平涂暗金。规范原文着色器 `az = mix(-0.5, 0.35, uPhase)`
  保持光源始终在前方，已照抄移植（含 `rot = uPhase * π` 主作用域声明、uBright 定格 1.25）。
- **黄雾**：DOM 层星空极光/光晕两层大范围暖色 wash 未在亮主题禁用 + Hero 天空渐变过大。
- **光晕白爆**：旧单层强晕；规范三层衰减（亮核/中晕/外晕，exp(-g·9)/exp(-g·3.2)/exp(-g·1.5)）已照抄。

### 修复（仍全部在白名单内）

1. `planetDawnGL.js`：着色器换为规范原文实现（az 前置光源、三层光冕、珍珠高光 pow26、
   菲涅尔缘光、fbm 表面纹理），数学结构逐字未动；仅色值/强度微调，见偏差⑥。
2. `dawn.css`：`.starry-root` 极光/光晕层亮主题 `background:none`；Hero 天空径向渐变收紧为
   **以球心为圆心、2.5 倍球半径（375px）归零**，之外纯净 `--bg-base`；揭示层同一渐变（淡出无缝）。
3. `HeroCanvas.vue`（纯新增）：实测球心/球径注入 `--dawn-cx/--dawn-cy/--dawn-glow-r`，
   天空暖光域随窗口尺寸自适应，且修复了刷新直入白昼时渐变圆心默认值偏差。

### 偏差⑥（v3 新增，反剪影必需）

规范原文色值在 #F7F3EC 亮天上**必然剪影**（演示页原文管线实测：球心 214.9 < 局部背景 227.7，
另有 alpha 双重相乘泥环 159.9，见 `v3-demo-180-vs-app.png` 左面板与 `v3-demo-profile-180.txt`），
与规范禁令「不许球比背景暗」直接冲突。数学结构不变，仅调三个色值/强度参数：

| 参数 | 原文 | 交付 | 依据 |
|---|---|---|---|
| alb 点亮混色系数 | 0.38 | **0.45** | 用户确认的浓金安全区（演示页旋钮对比实测；0.55 偏淡、0.38 球缘剪影） |
| alb 目标色 | (1.0,0.82,0.48) | ×1.2 | 演示页旋钮网格实测 |
| 白昼环境光端点 lit | 0.76 | **1.30** | 与 0.45 配套：补住球缘区使其贴平天空（0.7R 实测 222.9 vs 天空 ~230，纹理噪声内）；1.30 为浓金方向上限 |
| 光冕加法窗口 win | —（原管线 a 混合） | 0.08，1.57R 起收 2.5R 归零 | 亮天上 0.12 会洗白半屏（中晕 254.5 顶白）；0.08 层次清晰 |

> v3 首版交付为 0.55/1.15；用户用演示页旋钮试参后选定 0.45/1.30（候选C），
> 实测证据更新为 `v3c-dawn-rest.png` / `v3c-ball-closeup.png`：
> 球心 236.8、菲涅尔环 244.1、光冕 244.5→243.2→240.3→2.5R 回页底 242.3，四角干净无洗屏。

**物性说明（如实报告）**：filmic 映射 `1-exp(-col·1.6)` + pow 0.92 下，"浓郁暖金"色球亮度上限
≈225~231，而米白天空 227~243——「球最亮」与「浓金」存在固有权衡，交付取球体优先
（偏亮的淡金）。整条「球心 > 亮环 > 中晕 > 外晕 > 背景」在加法光冕+亮天空下物理上不可严格成立
（光冕是在最暖的天空上做加法），规范指定的验收目标（演示页路线 C 面板）呈同一序关系，
实现与该目标同级。若想更浓的金色或更弱的日冕，演示页旋钮可实时预览取舍。

## 二补四、v6 白昼物理化：HDR 管线 + 着色器接管天空 + 绽放时序 + 半径驱动翻转

### 用户反馈（规范第〇步，三个实测缺陷）

1. 白昼"恒星"物理不成立：球心亮度 235 < 四周天空 236，球比它照亮的天空还暗
   （根因：亮天空上加法光晕余量仅 0.04，tonemap 把一切压平）；
2. 天空不响应光照：白昼天空是平的米色，没有以星球为源的径向辐照；
3. 绽放帧缺席（uBright=1.5 过冲被揭示层盖住）+ 转场中段约 0.3s 文字灰影 + 揭示圈硬边橙环。

### 实现（全部在白名单内）

- **`src/theme/planetDawnGL.js`**：`FRAG_SRC` 全量替换为规范 v6 GLSL（数学结构逐字未动）。
  天空/光冕/球体在线性空间累加，各分支内 filmic tonemap；白昼天空由着色器接管
  （`skyLin=(2.11,1.86,1.57)` 为 #F7F3EC 在该 tonemap 下的精确线性逆，远端逐色回落），
  径向暖辐照 `×(1.22,1.04,0.80)^exp(-g·2)`；天空随 `skyVis=smoothstep(0.88,1.00,uPhase)`
  以 alpha 0→1 浮现（不产生灰方块）；两条 ×uPhase² 恒星自发光项（黑夜免疫）。
- **偏差⑦（v6 新增，必须披露）**：规范 v6 GLSL 原文无 `uScale`，其画布为全屏；
  本实现画布为 3×球径的星球盒，缺 `uScale=1/(0.5742×3)` 球体会放大 1.72 倍，
  违反布局 immutable 与黑夜零回归。按规范"只许改色值与尺寸参数"条款复引入 uScale
  （视直径尺寸参数），其余数学一字未动。
- **`src/theme/useDawnTransition.ts`**：① 绽放时序 —— bright 1.0→1.18（0.05→1.6s 随自转爬升）
  → 1.5（1.6→1.85s，此时揭示圈已铺满画布，绽放才可见）→ 保持 0.2s → 1.25（2.05→2.4s）；
  ② 半径驱动翻转 —— `state.radiusK >= flipRadiusK` 即翻转 data-theme（两方向同一阈值，
  无迟滞），`setDawnFlipRadiusK` 供 HeroCanvas 注入几何阈值，缺省 1（非首页入口安全回退）。
  时间线结构/tween 数量/状态机均未动，仅 bright 排程与 sync 翻转判据两处修改。
- **`src/components/home/HeroCanvas.vue`**：① `captureFreeze()` 末尾注入
  `flipRadiusK = (球心→.hero-copy 最远角距离 + 40px) / maxDist`（本机实测 textDist=951、
  maxDist=1197 → flipK=0.828）；② `drawCentralGlow` 在白昼不画（v6 §六：2D 层不加径向光，
  天空归着色器），两处调用点同一守卫。

### 规范内部冲突（按铁律停报，由人决定，不擅自改动）

v6 规范的"着色器照抄"与"验收锚值/零回归"存在三处数学上不可兼得的冲突，
而禁止清单（禁改 tonemap/skyLin/两条自发光参数、禁只调系数）堵死了所有调和路径：

1. **黑夜光晕**：规范断言 v6 分支"uPhase=0 时输出与现版完全一致的纯加法光晕"——实测不成立。

   现版（v3/v5）有 `light·a³` 抑制（g=0.05 处 a³≈0.014）。结果临边 +38.7 vs 现版 +0，
   验收⑤在 1.02–1.2R 区间不达标。修复需改动禁止清单所禁的数学（如复引入抑制项），故停报。
2. **白昼球心 R 通道**：锚值 ≥(252,250,240)，实测均值 (250.0,249.8,249.2)。核心已饱和

3. **白昼球面中部**：锚值"中球暖金 ≈(237,234,222)"，实测 0.5R 处 (251,251,249)。

### 规范内部冲突（按铁律停报，由人决定，不擅自改动）

1. **验收②"光晕峰 ≤球心−5"在本规范自己的保护条款下数学不可达**。
   规则③保护的白昼天空架构中，球面临边处的天空辐照项
   `skyLin·mix(1,(1.22,1.04,0.80),exp(-g·2))` 单独（光冕系数全部置零）即 tone 到 lum≈247；
   而球心帧缓冲均值 ≈251–253。"光晕峰 ≈240"锚值与 v7.3 给定参数 + 受保护天空架构不可兼得
   （要压到 240 必须改动禁改的天空辐照或 tonemap），故停报。实测光晕峰 ≈249–251 ≤ 球心，
   单调性"球心最亮"成立。
2. **偏差⑧（新增）：调参台重编译耗时超出 100ms 预算**。实测 367–576ms
   （Windows ANGLE/D3D 着色器编译延迟，随驱动而定；代码已按规范在超预算时 console.warn 自报）。
   面板为开发期一次性工具、仅 `?dawnlab=1` 挂载、正式用户不可见，生产路径零影响，故如实披露。

### 取证方法披露（v7.3 新增）

- **截图管线系统性压暗 ~2–4 级**：本机 CDP 截图经合成器色彩管理，球心单像素在截图中
  读得 246–253，而 GL 帧缓冲 `readPixels` 直读为 (255,255,24x)。验收①的单像素=255 与
  3×3 均值以帧缓冲直读为准（uPhase=1 定格预览态 = 白昼恒星态同参数同着色器）；
  截图口径的 3×3 (249.6,248.4,238.7) 亦已达标，两口径互证。
- **CDP 截图停顿会触慢帧降级**：本调试环境中 take_screenshot 造成多秒帧间隔，
  HeroCanvas 慢帧保护（degradeLevel 2）会停渲染循环 → 后续截图为冻结帧。
  取证时以 `drawArrays` 计数探针确认循环存活（74fps），谷物分布采样改在页内
  `drawArrays` 钩子内同任务 `readPixels`（后台缓冲有效），避免截图管线干扰。
  该降级为开发环境取证伪影：正常前台使用帧间隔为毫秒级，不触发。
- 其余同 v4/v6：isActive 猴子补丁步进（页面内存态，源码零改动）+ 0.9s 消滞后。

### 交付后缺陷与修复（fix6）：白昼定格文字被 GL 天空画布整片遮挡

**缺陷（用户截图两次实测）**：白昼定格态，Hero 标题/副标题右段被一块直角边浅色区域截断
（"穿越星海，抵达你的新星"只剩左半）。遮挡区左缘 = GL 画布左缘，与视口几何相关
（用户 1705px 视口画布左缘 x=700 恰切标题中段）。

**根因（层叠链实测）**：`.planet-gl-overlay`(z-index:60，v6 设定"星球高于揭示层")
高于 `.hero-grid`(z-index:1)。GL 画布为 3×球径方盒，skyVis=1 时整盒为不透明白昼天空；
当画布与文字水平重叠时，重叠段文字被不透明天空盖住。黑夜画布全透明故不可见。
`elementFromPoint` 因 overlay `pointer-events:none` 跳过该层，静止探测会误判"无遮挡"，
须以强制重叠截图验证。

**修复（dawn.css 追加一条，白名单内，不动布局/结构/尺寸）**：
`html[data-theme='dawn'] .home-hero .hero-grid { z-index: 70; }`
（hero-grid 本已 position:relative；70 > overlay 60、< 导航 100）。
仅天空区域受层叠影响（球体与文字无水平重叠）；正/反向主题翻转瞬间文字均被揭示层遮盖，
层叠切换不可见，转场视觉不变；规则破晓态作用域，黑夜零影响。

**复验**：强制重叠几何（画布左移 300px 使左缘切入标题中段）修复前文字截断、
修复后完整（`fix6-text-over-sky.png`）；真实播放 夜→昼→夜 循环后两态定格均干净
（`fix6-dawn-after-cycle.png` / `fix6-night-after-cycle.png`）；正常几何白昼定格完整。
